About

I work on the layer where software meets hardware — state estimation for mobile robots, processor architecture, and the electromagnetics underneath it all. Most of what I build starts as a question I couldn't answer by reading, so I simulate it instead.

Projects

Monte Carlo Localization Simulator

A real-time particle filter that localizes a robot inside a 2D map using simulated LIDAR. Runs 1,000 particles through motion and measurement updates each frame, resampling against raycast range readings to converge on the true pose. Built to understand why MCL works, not just that it does.

Python · NumPy · Pygame · particle filters · raycasting

Electromagnetic Field Visualization

Numerical solvers and plots for electric field and potential distributions from discrete charge configurations — turning the closed-form integrals from electromagnetics into something you can actually look at.

Python · NumPy · Matplotlib

ARM Assembly Sandbox

A working bench for ARM instruction-level experiments — testing addressing modes, branching behavior, and register conventions directly against hardware semantics rather than trusting the lecture slides.

ARM assembly · computer architecture
